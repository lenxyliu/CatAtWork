# BC-009 — A later edit can erase defect and test history

- Status: fixed
- ISSUE: ISSUE-006
- First observed: 2026-07-23
- Affected versions: pre-governance documentation workflow
- Fixed versions: clean governance baseline (pre-push)
- Regression test: governance checker negative/positive fixture suite
- Automated evidence: TR-GOVERNANCE-20260723-001; refreshed by TR-BASELINE-20260723-003
- Device evidence: not applicable

## Preconditions

A fix is described by mutable current-state Markdown without stable IDs, immutable executions, or a content digest.

## Reproduction

Make a later optimization and update the same audit/status file; omit a badcase or reuse an old passing test result after code changes.

## Expected

History is append-only and CI rejects missing links, fields, stale digests, record rewrites and invalid trivial exemptions.

## Actual

Earlier context/results can be overwritten and there is no automated proof that the recorded test exercised final content.

## Root cause

No repository-wide change protocol or automated governance gate.

## Impact

Regressions are rediscovered without their prior reasoning, and “fixed” claims become unauditable.
