  --manifest Sources/CatAtWork/Resources/DefaultPet.catpet/manifest.json \

Compare the exit status and report with the accepted B1 failure scopes.

## Expected

The validator emits a deterministic report whose content digest, tool
versions, package/action/frame identities, metrics, threshold sources and
waiver identities are complete. Baseline mode accepts only the exact approved
known-failure set. Release mode fails on any error or unwaived warning.

## Actual

The command exits 0 and writes `ok: true` with `errors: []` even though the
same package has accepted content-matched failures in geometry, color,
canonical scale/identity proxies, root/support, connected components,
endpoint pose, locomotion, cadence and delayed render-snapshot integrity.
The legacy report has no mode, normalized finding identity, threshold source,
waiver contract or deterministic baseline comparison.

## Root cause

Confirmed acceptance-policy gap: the legacy validator aggregates a small set
of package checks, treats continuity findings as non-blocking warnings and has
no complete, schema-governed evidence input for runtime metric families.

## Impact

Automation can approve a known-defective package, and two equivalent
executions cannot be compared as a stable release decision.
