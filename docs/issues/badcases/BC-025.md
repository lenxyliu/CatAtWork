## Preconditions

Use current atlas crops, manifest `startPose`/`endPose`, and the root-aligned
endpoint matrix. Review both endpoints of every action.

## Reproduction

1. Generate the first/last crop matrix for all 31 actions.
2. Display each declaration above its two current crops.
3. Assign an observed pose independently for the start and end.
4. Preserve the complete decision table in `endpoint-pose-review.json`.

## Expected

All 62 endpoints visibly satisfy their declared pose.

## Actual

All **31 actions were reviewed**. Twenty-nine actions match at both endpoints.
`backPet` declares `seated→seated` but is standing/crouched at both endpoints;
`bellyPet` declares `seated→seated` but is lying/crouched at both endpoints.
Thus two actions and four endpoints fail.

## Root cause

Confirmed package-contract mismatch: metadata and the shipped endpoint pixels
disagree. B1 does not decide whether B3/B4 should alter metadata or artwork.

## Impact

The pose router can omit a needed authored bridge and create a visible
cross-pose transition.
