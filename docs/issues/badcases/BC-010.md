# BC-010 — Hosted CI uses a compiler older than the package tools version

- Status: fixed-unverified
- ISSUE: ISSUE-007
- First observed: GitHub Actions run 29977724140 on 2026-07-23
- Affected versions: baseline commit 856511e86b060979409fde02d8d8d4a98215751b
- Fixed versions: `codex/ci-swift6-baseline`, pending hosted verification
- Regression test: hosted `swift` job prints Xcode/Swift identity, builds, runs 36 unit tests and completes package/source validation
- Automated evidence: failed run 29977724140; TR-CI-20260723-001
- Device evidence: not applicable to hosted toolchain selection

## Preconditions

The workflow runs the Swift job on the GitHub-hosted `macos-14` image while
`Package.swift` declares `swift-tools-version: 6.0`.

## Reproduction

Push baseline commit `856511e86b060979409fde02d8d8d4a98215751b` and
inspect the `Swift build` step in Actions run `29977724140`.

## Expected

The hosted compiler supports Swift tools 6.0, its identity is present in the
log, and build/test/package validation executes.

## Actual

The runner invokes Swift 5.10 and exits before compilation with
`package 'catatwork' is using Swift tools version 6.0.0 but the installed
version is 5.10.0`.

## Root cause

The workflow selected `macos-14` without an explicit Xcode contract. That
image's default command-line toolchain was older than the package manifest.

## Impact

The authoritative branch check is red even though the same baseline builds
and passes 36 tests under the supported local Swift 6 toolchain. Main
protection cannot safely require the check until the runner contract is fixed.

## Status timeline

- 2026-07-23: baseline Actions run failed before compilation.
- 2026-07-23: changed the job to `macos-15`, pinned Xcode 16.4 through
  `DEVELOPER_DIR`, and added an identity step; hosted rerun pending.
