- Device evidence: endpoint matrix and clean native app inspected

## Preconditions

Root-align current atlas crops and compare endpoints having the same declared
pose. Keep `bodyScale = 1` and the package's 220 pixels/body-unit contract.

## Reproduction

1. Generate all current action sheets.
2. Root-align each action's first and last crop on the 665×737 runtime canvas.
3. Compare seated endpoints using upper-silhouette width and visible area;
   compare standing locomotion endpoints separately.

## Expected

Comparable-pose head/upper-silhouette scale differs by no more than 3% and
torso scale by no more than 5%.

## Actual

Comparable seated starts include `wave` upper-silhouette width **119 px**,
`idle` **159 px**, `curious` **172 px** and `petting` **174 px**. The
`petting`/`wave` ratio is **1.462×**, far beyond the declared canonical
budget. Standing action endpoints also vary materially in width and body
proportion.

## Root cause

Confirmed contract mismatch: all frames declare the same package density and
runtime body scale, but current content uses inconsistent comparable-pose
anatomical scale. B1 does not choose the future canonical reference.

## Impact

Action transitions change the perceived size and model of the character.
