# BC-012 — Hosted asset validation lacks its Pillow dependency

- Status: fixed-unverified
- ISSUE: ISSUE-009
- First observed: GitHub Actions run 29984822374 on 2026-07-23
- Affected versions: branch commit 92bd7bf
- Fixed versions: `codex/ci-swift6-baseline`, pending hosted verification
- Regression test: hosted identity reports Python 3.13/Pillow 12.3.0 and high-frame validation returns success
- Automated evidence: failed run 29984822374; TR-CI-20260723-002
- Device evidence: not applicable to hosted dependency provisioning

## Preconditions

`Scripts/validate_high_frame_pet.py` imports `PIL.Image`, and the hosted runner
does not happen to include Pillow in its active Python environment.

## Reproduction

Run the `Package and source validation` step from Actions run `29984822374`.

## Expected

Every validation dependency is installed from a versioned repository file,
its identity is logged, and high-frame package validation executes.

## Actual

Typecheck/core smoke passes, then Python exits with
`ModuleNotFoundError: No module named 'PIL'`.

## Root cause

The workflow relied on the developer machine's preinstalled Pillow package
and did not provision a Python validation environment on GitHub Actions.

## Impact

The authoritative Swift job remains red after build and all 36 unit tests
pass, and image-package correctness is never evaluated on the hosted runner.

## Status timeline

- 2026-07-23: PR run `29984822374` failed at the Pillow import.
- 2026-07-23: added Python 3.13 setup, pinned Pillow 12.3.0 and identity
  logging; hosted rerun pending.
