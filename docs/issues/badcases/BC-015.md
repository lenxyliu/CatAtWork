# BC-015 — Validator uses Pillow APIs scheduled for removal

- Status: open
- ISSUE: ISSUE-012
- First observed: GitHub Actions run 29985577013 on 2026-07-23
- Affected versions: `Scripts/validate_high_frame_pet.py` at branch commit 860ab88
- Fixed versions: none
- Regression test: Pillow 12.3 validation emits no getdata deprecation warning and produces the same report
- Automated evidence: Actions run 29985577013 package/source validation log
- Device evidence: not applicable to Python validation tooling

## Preconditions

Run the high-frame validator with Pillow 12.3.0.

## Reproduction

Execute the package/source validation step from Actions run `29985577013`.

## Expected

Validation completes without APIs scheduled for removal and returns the same
geometry/alpha findings.

## Actual

Pillow reports two uses of `Image.Image.getdata` as deprecated and scheduled
for removal in Pillow 14.

## Root cause

The validator predates Pillow's `get_flattened_data` replacement.

## Impact

Current validation passes, but a future Pillow 14 upgrade will break alpha
scanning unless the API migration is verified first.

## Status timeline

- 2026-07-23: recorded from passing run `29985577013`; scheduled as a
  separate compatibility change on `codex/pillow14-validator`.
