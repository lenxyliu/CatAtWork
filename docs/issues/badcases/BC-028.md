- Status: historical-regression
- Classification: historical-regression

- Automated evidence: QA root `Assets/CatAtWork/qa/b1-current-build-0ca2b518`; scope digest `9903c77a71c2455a092d0eec83ba527556ba4bb07e1cdae945977184472b5847`
- Device evidence: Apple M4 Pro Metal device; historical recording retained separately

## Preconditions

Fix current body state to `idle` frame 1, root (1000, 0), source 290×392,
pivot (0.5, 0.9591836735) and the same atlas/texture rect. Vary only the
runtime shader eye offset for all 16 signed direction indices.

## Reproduction

1. Compile and run `metal-visual-probe.swift`.
2. Render the 16 current eye offsets from -9.8 through +11.2 source pixels.
3. Compare every RGBA pixel, alpha area/bounds and body-state field with the
   neutral direction.

## Expected

Only the bounded eye ROI changes; body action/frame/root/geometry/atlas remain
invariant and whole-body alpha bounds do not change.

## Actual

All state fields remain invariant. Pixel changes are contained in one
**89×17 px** head region; zero changed pixels occur outside its union.
All 16 outputs retain alpha area **63,517** and alpha bounds
**258×360 at (16,16)**. The historical whole-body jump does not reproduce.

## Root cause

The historical path used direction artwork as body state. The content-matched
current path applies gaze in the shader and does not give gaze body-action
ownership. This is a current observation, not a claim about the exact commit
that removed the old behavior.

## Impact

No current whole-body gaze jump was found. The Issue remains useful as a
regression scope because no committed orthogonality gate exists yet.
