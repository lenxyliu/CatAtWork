## Expected

Non-semantic adjacent-frame width and anatomy changes remain within the Issue
acceptance budget; an isolated spike is a failure.

## Actual

`happy` frames 6→7 change width by **1.9448×** and visible area by
**1.5153×**; frames 14→15 change width by **1.7785×**. `bellyPet` frames
5→6 change width by **1.7250×**. The current validator still reports `ok:
true`.

## Root cause

Confirmed failure scope: the production atlas crops themselves contain the
measured geometry discontinuities. The provenance of the inconsistent source
frames remains a hypothesis and is not assigned as a confirmed cause in B1.

## Impact

The same action visibly changes volume and silhouette during playback, and the
existing release signal does not block it.
