# BC-014 — Checkout action still targets the deprecated Node 20 runtime

- Status: open
- ISSUE: ISSUE-011
- First observed: GitHub Actions run 29985577013 on 2026-07-23
- Affected versions: workflow at branch commit 860ab88
- Fixed versions: none
- Regression test: required checks complete without a Node 20 action-runtime warning
- Automated evidence: Actions run 29985577013 annotation
- Device evidence: not applicable to hosted action runtime

## Preconditions

The required workflow uses `actions/checkout@v4` on a current GitHub-hosted
runner.

## Reproduction

Run either required job at branch commit `860ab88` and inspect the job
annotations or final cleanup log.

## Expected

First-party Actions use a supported Node runtime and finish without
deprecation annotations.

## Actual

GitHub reports that checkout v4 targets deprecated Node 20 and is being forced
to run on Node 24.

## Root cause

The workflow retained checkout v4 after the official checkout action released
Node 24-based major versions.

## Impact

The current checks pass, but future runner enforcement can convert the warning
into a CI failure. Updating the major version must be verified independently
because it also changes credential-storage behavior.
