# BC-111 — Pointer pass is confused with petting or chase

- Status: device-pending
- ISSUE: ISSUE-111
- First observed: before 2026-07-23
- Affected versions: legacy pointer-distance recognizer
- Fixed versions: 2026-07-23 frozen workspace claim
- Regression test: pass, hover, pet and shoo produce distinct intents
- Automated evidence: frozen ISSUE-CLASSIFICATION section 3; legacy 36-test claim
- Device evidence: pending regional pointer capture

## Preconditions
Move the pointer across or near the cat without an intended gesture.
## Reproduction
Accumulate pointer distance through the former shared interaction counter.
## Expected
Pass affects gaze only; hover needs dwell; pet needs regional reciprocation; shoo needs fast reversal.
## Actual
Ordinary passes triggered chase or petting and made the cat overactive.
## Root cause
One distance accumulator drove multiple gesture meanings.
## Impact
False interactions and unstable autonomy.

- 2026-07-23: migrated; recognizer separation claimed, desktop acceptance pending.
