# BC-027 — Delay injection exposes current async transparent-frame window

- Status: open
- Classification: current-confirmed
- ISSUE: ISSUE-024; GitHub #19
- First observed: 2026-07-24
- Affected versions: app 1.0.3 (8), commit `0ca2b518d5a079ace1ef1e6d9a6892a5259b080e`
- Fixed versions: none
- Regression test: content-matched offscreen Metal delay probe; no production test hook
- Automated evidence: QA root `Assets/CatAtWork/qa/b1-current-build-0ca2b518`; scope digest `65fecfda346db306ef2f0d62271b9cc573f3925d2a5a2df0dfefe64175721fdd`
- Device evidence: Apple M4 Pro Metal device; no uninstrumented native occurrence is claimed

## Preconditions

Compile `metal-visual-probe.swift` against the current idle and walk atlases.
Use the byte-for-byte current fragment/vertex shader and the current draw
branch. Align the atlas switch immediately before a display sample.

## Reproduction

1. Establish a visible old snapshot.
2. Publish the new geometry, set `texture = nil` as current
   `requestTexture()` does, and delay publication of the new texture by
   0/16/50/100/250 ms.
3. Render every 60 Hz and 120 Hz sample through Metal and record visible alpha.
4. Do not infer a fix from this B1 test.

## Expected

Every transition sample shows either the old valid snapshot or the new valid
snapshot; visible alpha never reaches zero.

## Actual

Zero delay has no transparent sample. At 16/50/100/250 ms, the 60 Hz probe
renders **1/3/6/15** transparent frames and the 120 Hz probe renders
**2/6/12/30**. The transparent Metal output has alpha area 0 between valid
areas 63,517 and 53,462.

## Root cause

Confirmed state-publication sequence: the current view clears `texture`
before the async replacement is ready, and the draw path commits only the
transparent clear while it is nil.

## Impact

An atlas transition can make the pet disappear for one or more frames when
texture availability misses the display sample.

## Status timeline

- 2026-07-24: explicit B1 decision: visible defect reproduced under
  content-matched delay injection; classify `current-confirmed`; preserve the
  test and make no fix.
