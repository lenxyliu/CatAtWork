## Blocker

Every scoped interaction action requires exact frozen seated endpoints. A
local interaction-only color change would create visible endpoint flashes and
would silently deviate from ADR-0016/foundation-contract color rules. The
interaction slice must not install its 336 frames or open a publication PR
until a separately reviewed foundation color correction resolves this
evidence.
