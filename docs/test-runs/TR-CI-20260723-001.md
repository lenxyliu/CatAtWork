## Failure analysis

The failed local attempt was an environment permission failure, not a compiler
or source failure. Granting the normal Swift/Clang cache write path made the
identical build and all 36 tests pass. This reproduces and preserves the
already-known sandbox-cache badcase rather than hiding it.

## Retrospective

Testing the runner fix exposed that executable dotfiles were outside the
freshness boundary. A governance gate must test its own path classification;
otherwise a passing digest can provide false confidence about the very
workflow that enforces it.
