## Retrospective

A package is not only a collection of images; it is a runtime capability and
state contract. Compiling that contract once per session removes fallback
ambiguity and gives package switching a single publication boundary. The
failed preview regression also showed why replacement priority and pose safety
must remain independently selectable policies.
