## Retrospective

Moving only the outer UI call into a task would not have fixed either badcase.
The durable boundary is end-to-end: cancellation must reach the child and file
loops, output must drain while the process runs, a validated package must be
published by generation, and a decoded texture must be admitted through a
session namespace with an explicit byte budget. Concurrency tests likewise
need to assert shared results, not scheduling order.
