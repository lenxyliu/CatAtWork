rendering behavior; it moves wrapper construction to the caller so only the

## Retrospective

Cross-toolchain Swift concurrency checks must be treated as an interface
contract. Legacy framework objects need their reviewed sendability adapter on
the producing actor, not after they have already crossed into another actor.
