## Tested content

Fresh candidate-9 foundation rebuild and its intended byte comparison with
the 216 installed foundation frames.

## Commands

The combined reproduction command built and validated candidate 9, then used
`seq -w 0 23` to construct expected three-digit frame names for `cmp`.

## Passed

The fresh assembler completed 216 frames; canonical packaging completed nine
actions; the B2/custom foundation validator passed; deterministic QA built.

## Failed

BSD `seq -w 0 23` emitted two-digit names such as `00.png`, while production
uses three-digit names such as `000.png`. Every attempted `cmp` therefore
reported a missing source path.

## Skipped

The intended 216 content comparisons did not execute.

## Failure analysis

The filename generator was incompatible with the repository's three-digit
frame convention. This is a command-construction failure, not an asset or
oracle failure.

## Evidence

The failed command output is preserved in the primary task execution record.
Generated artifacts remain outside Git under
`/private/tmp/catatwork-b4-interaction-prechange.763PF6`.

## Retrospective

Generate frame names with explicit `printf '%03d'` rather than platform-
dependent sequence padding.
