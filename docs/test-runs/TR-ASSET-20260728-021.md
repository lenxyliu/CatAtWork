## Failure analysis

The equal-weight pull computes each governed output channel halfway between
the source pixel and one material target. Therefore every unclipped
same-material color residual is multiplied by one half. The existing oracle
measured only material location with median ΔE00; it could pass even while
the transformation deterministically suppressed local luminance and chroma
texture. The next candidate must preserve local detail residuals explicitly
and add a content-matched detail-retention gate rather than weakening direct
native evidence.

## Retrospective

texture/detail retention. Median ΔE alone cannot prove perceptual fidelity.
