## Retrospective

Pose routing and priority arbitration must share the same activation boundary.
Storing target intents separately from the selected atomic plan makes that
boundary explicit and testable. Force semantics also need a regression at
this boundary because clearing only the waiting queue would leave an invisible
continuation able to resume after an emergency action.
