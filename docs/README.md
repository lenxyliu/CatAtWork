# Engineering record index

- `design/`: evolving system intent; every strategic revision appends a CHG-linked revision row.
- `adr/`: immutable accepted architecture and policy decisions.
- `issues/`: stable issue register and independent badcases.
- `changes/`: one immutable-after-merge change record per non-trivial change.
- `test-runs/`: immutable execution records, including failures and skipped items.
- `audits/`: immutable candidate-build and release audits.
- `recovery/`: prehistory archive manifests and restoration instructions.
- `templates/`: required fields for new records.

The root `ISSUE-CLASSIFICATION.md` and `COMPLETION-AUDIT.md` are frozen 2026-07-23 evidence. Never update them to describe a later state; create new ISSUE, TR, and audit records instead.
